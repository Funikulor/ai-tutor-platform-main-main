# 🚀 Быстрая установка локальной нейросети

## Что нужно сделать (5 простых шагов):

### Шаг 1: Установить Ollama

**Самый простой способ:**
1. Откройте https://ollama.com/download
2. Скачайте установщик для Windows
3. Запустите установщик и следуйте инструкциям
4. Ollama установится и запустится автоматически

### Шаг 2: Скачать модель

После установки Ollama откройте PowerShell и выполните:

```bash
# Рекомендуемая модель (быстрая, хорошо работает)
ollama pull llama3.2
```

Или для лучшей поддержки русского языка:
```bash
ollama pull qwen2.5:1.5b
```

Это займет несколько минут (модель ~2GB).

### Шаг 3: Настроить Backend

Создайте файл `.env` в папке `AdaptEd/backend/`:

**Способ 1: Вручную**
1. Откройте папку `AdaptEd/backend/`
2. Создайте новый файл с именем `.env` (без расширения)
3. Скопируйте туда:
```
ASSISTANT_PROVIDER=ollama
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=llama3.2
```

**Способ 2: Через PowerShell**
```powershell
cd "AdaptEd\backend"
@"
ASSISTANT_PROVIDER=ollama
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=llama3.2
"@ | Out-File -FilePath .env -Encoding utf8
```

### Шаг 4: Проверить работу

Проверьте Ollama вручную:
```bash
ollama list
ollama run llama3.2 "Привет!"
```

### Шаг 5: Запустить проект

1. **Backend:**
   ```bash
   start_backend.bat
   ```

2. **Frontend (в другом окне):**
   ```bash
   start_frontend.bat
   ```

3. Откройте браузер: http://localhost:3000
4. Перейдите в "Чат с ИИ" и попробуйте написать сообщение!

## ✅ Готово!

Теперь ваш чат работает с локальной нейросетью! Все данные обрабатываются на вашем компьютере, интернет не нужен.

## ❓ Проблемы?

### Ollama не запускается
- Перезагрузите компьютер после установки
- Или запустите вручную: `ollama serve`

### Модель не отвечает
- Проверьте, что модель установлена: `ollama list`
- Если нет, установите: `ollama pull llama3.2`

### Backend не подключается
- Убедитесь, что файл `.env` создан в `AdaptEd/backend/`
- Проверьте, что Ollama запущена: `ollama list`
- Перезапустите backend

### Медленные ответы
- Это нормально для локальной нейросети (особенно на слабых ПК)
- Попробуйте более легкую модель: `ollama pull qwen2.5:1.5b`
