> **Скобки** говорят: «сначала воспринимай выражение **внутри** как целое». Если перед скобкой стоит **множитель**, его нужно **распределить** на **каждое** слагаемое внутри — иначе равенство превратится в фантазию.

## Дистрибутивность (раскрытие скобок)

Для чисел и базовых выражений:

- **k(a + b) = ka + kb**
- **k(a − b) = ka − kb**

**Пример.** `2(x + 3) = 2x + 6`

**Минус перед скобкой** — это множитель **−1** (или общий «−» на группу):

`−(x − 5) = −x + 5`  
(оба слагаемых внутри **сменили знак**)

**Двойной знак при умножении:** `−3(x − 1) = −3x + 3`, потому что (−3)·(−1) = **+3**.

> **Ловушка №1:** писать `−3(x − 1) = −3x − 3` — **неверно**: последнее слагаемое должно быть **+3**.

## Полный разбор (как в контрольной)

**Задача A:** `2(x + 1) = 8`

1. Раскрыть: `2x + 2 = 8`
2. Перенести **+2**: `2x = 6`
3. Разделить на 2: **`x = 3`**
4. Проверка: `2(3 + 1) = 8` ✓

**Задача B (как в проверочном вопросе курса):** `3(x − 2) = 9`

1. Раскрыть: `3x − 6 = 9`
2. Перенести **−6** вправо → на правой стороне **+6**: `3x = 9 + 6` → `3x = 15`
3. Разделить на 3: **`x = 5`**
4. Проверка: `3(5 − 2) = 3·3 = 9` ✓

---

## Смешанный пример: число, минус и скобка

**Задача:** `5 − 3(x − 1) = 2`

1. Раскрываем **только** `−3(x − 1) = −3x + 3`  
   Получаем: `5 − 3x + 3 = 2`
2. Собираем числа слева: `8 − 3x = 2`
3. Переносим (удобно «красивые» слагаемые): `−3x = 2 − 8` → `−3x = −6`
4. Делим на **−3**: **`x = 2`**
5. Проверка: `5 − 3(2 − 1) = 5 − 3 = 2` ✓

---

## Скобки «для группировки»

`(x + 4) + 2 = 9` → `x + 6 = 9` → **`x = 3`**. Скобки не всегда означают «сложное раскрытие» — иногда они лишь показывают порядок сложения.

---

## Порядок работы в задаче со скобками

1. **Раскрой скобки** (внимательно со знаками).
2. **Приведи подобные** в каждой части, если нужно.
3. **Перенеси** все с **x** в одну сторону, **числа** — в другую.
4. Приведи к виду **`kx = b`** и **раздели** на k (k ≠ 0).
5. **Проверь** подстановкой в **исходное** уравнение (не в промежуточный черновик с ошибкой).
