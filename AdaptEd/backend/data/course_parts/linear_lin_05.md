> **Финиш базового курса:** соберём **одну дорожку** решения от «вижу уравнение» до «записал ответ и проверил», плюс **особые случаи**, когда x «исчезает», и список ошибок, за которые снимают баллы.

## Универсальный алгоритм (проговаривай по шагам)

1. **Раскрой скобки** (если есть); упрости каждую часть (приведи подобные).
2. **Перенеси** все слагаемые с **x** в одну сторону (часто влево), все **чистые числа** — в другую; при переносе — **смена знака**.
3. Приведи подобные среди x и среди чисел: `3x + 2x = 5x`, `7 − 2 = 5`.
4. Получил **`kx = b`**, **k ≠ 0**? Раздели **обе** части на k.
5. **Проверь** подстановкой в **исходное** уравнение.

Нарисуй в полях короткую «лесенку» из этих пяти пунктов — на контрольной это снижает панику.

## Плотный разбор

**Задача 1:** `4(x + 1) = 20`

- Шаг 1: `4x + 4 = 20`
- Шаг 2–3: `4x = 20 − 4` → `4x = 16`
- Шаг 4: **`x = 4`**
- Проверка: `4(4 + 1) = 20` ✓

**Задача 2:** `2x + 3 = x + 10`

- Перенос: `2x − x = 10 − 3` → **`x = 7`**
- Проверка: слева 2·7 + 3 = 17, справа 7 + 10 = 17 ✓

*(Первый шаг в вопросе курса про «рациональность» — как раз **раскрыть скобки** в `4(x+1)=20` или эквивалентно сразу разделить обе части на 4, получив `x+1=5`; оба приёма корректны, но раскрытие часто привычнее.)*

## Особые случаи: когда x «пропал»

### 1) Бесконечно много решений (тождество)

**Пример:** `2x + 4 = 2(x + 2)`  
Правая часть: `2x + 4`. Получается **`2x + 4 = 2x + 4`** — одно и то же слева и справа.  
**Любой** x подходит → **бесконечно много решений**.

### 2) Нет решений

**Пример:** `2x + 1 = 2x + 5`  
После переноса: `1 = 5` — **ложь** при любом x → **решений нет**.

> Не паникуй, если x сократился: посмотри, осталось ли **верное** числовое равенство (тождество) или **неверное** (противоречие).

## Типовые ловушки (контрольные и экзамены)

| Ловушка | Как не попасть |
|---------|----------------|
| Складывали **несовместимое**: `2x + 3` как `5x` | Складывай только **подобные**: `2x+3x`, числа **отдельно** |
| Раскрыли скобку с **не тем знаком** | Пересчитай **каждый** член: `−3(x−1)` даёт **+3** в конце |
| Делили только одну часть | Всегда **симметрично** обеим частям |
| Проверили не то уравнение | Подстановка в **исходное** |

## Задачи «словами»: схема моделирования

1. Обозначь неизвестное (**x** — то, что просят найти).
2. Запиши **две выражения** для одной и той же величины из условия.
3. Приравняй их — получилось уравнение.
4. Реши по алгоритму выше; ответ **в единицах задачи** (руб., км, шт.).

**Мини-пример.** «На два яблока и три груши потратили столько же, сколько на пять яблок» — пусть яблоко x, груша y; нужна ещё одна связь или фиксированная цена; идея: **одна величина выражается двумя способами** → **=**.
