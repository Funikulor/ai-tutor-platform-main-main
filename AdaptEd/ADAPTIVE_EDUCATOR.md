# Адаптивный педагог-аналитик

## Описание

Адаптивный педагог-аналитик — это система, которая ненавязчиво собирает данные об ученике в процессе диалога и тестирования для персонализации обучения.

## Возможности

### Сбор данных

Система собирает три типа данных:

1. **Академические признаки:**
   - Уровень знаний по предметам (математика, литература и др.)
   - Темы, вызывающие затруднения
   - Скорость выполнения заданий
   - Типичные ошибки и паттерны ошибок

2. **Когнитивные и поведенческие признаки:**
   - Стиль обучения (визуал/аудиал/кинестетик)
   - Уровень мотивации
   - Эмоциональное состояние
   - Стиль взаимодействия

3. **Метрики прогресса:**
   - Динамика результатов тестов
   - Частота обращений за подсказками
   - Прогресс по неделям/месяцам

### Этичность и прозрачность

- При первом взаимодействии система сообщает об этике сбора данных
- Ученик может отключить сбор данных командой `/стоп-сбор`
- Можно включить сбор данных обратно командой `/включить-сбор`
- Все данные анонимизируются

## API Endpoints

### 1. Получить аналитику ученика

```http
GET /assistant/analytics/{user_id}
```

**Ответ:**
```json
{
  "student_id": "123",
  "academic_traits": {
    "math_level": "средний",
    "weak_topics": ["дроби", "геометрия"],
    "test_accuracy": "75%",
    "typical_errors": ["calculation_error"],
    "task_completion_speed": 120.5
  },
  "behavioral_traits": {
    "learning_style": "визуал",
    "motivation_level": "высокая (активные запросы)",
    "emotional_state": "позитивный",
    "interaction_style": "активный"
  },
  "progress_metrics": {
    "hint_requests_frequency": 5,
    "weekly_progress": {
      "2024-W15": 75.0
    },
    "monthly_progress": {
      "2024-04": 75.0
    },
    "improvement_areas": [],
    "strengths": []
  },
  "data_collection_enabled": true,
  "total_interactions": 42
}
```

### 2. Обработать результат теста

```http
POST /assistant/analytics/test-result
```

**Тело запроса:**
```json
{
  "user_id": "123",
  "subject": "математика",
  "accuracy": 75.0,
  "errors": ["дроби", "уравнения"],
  "time_spent_seconds": 300.0
}
```

**Ответ:**
```json
{
  "analytics_updated": true,
  "reflection_question": "Как тебе эта задача? Было ли что-то непонятно?",
  "personalized_suggestion": "В прошлом тесте были ошибки в теме 'дроби'. Давай разберём пример вместе?"
}
```

### 3. Обработать попытку выполнения задания

```http
POST /assistant/analytics/task-attempt
```

**Тело запроса:**
```json
{
  "user_id": "123",
  "is_correct": false,
  "error_type": "calculation_error",
  "time_spent_seconds": 45.0
}
```

**Ответ:**
```json
{
  "analytics_updated": true,
  "suggestion": "Есть ошибка типа 'calculation_error'. Хочешь попробовать ещё раз с подсказкой?"
}
```

### 4. Чат с автоматическим сбором данных

```http
POST /assistant/chat
```

Система автоматически собирает данные из диалога. При первом взаимодействии возвращается `ethics_message`.

**Ответ может содержать:**
```json
{
  "message": "Ответ ассистента...",
  "ethics_message": "Привет! Я помогаю персонализировать твоё обучение...",
  "personality_insights": {...}
}
```

## Интеграция

Система автоматически интегрирована в:

1. **Чат-ассистент** (`/assistant/chat`) — собирает данные из диалогов
2. **Систему подсказок** — записывает частоту запросов подсказок
3. **CognitiveProfile** — синхронизирует данные с существующим профилем

## Примеры использования

### Пример 1: Анализ диалога

Ученик пишет: "Не понимаю, как решать уравнения с двумя переменными"

Система:
1. Тегирует запрос как "слабая тема: алгебра — системы уравнений"
2. Адаптирует ответ: "Давай разберём простой пример с картинкой!"
3. Предлагает тест с выбором уровня сложности

### Пример 2: Обработка стресса

Ученик пишет: "Я никогда это не пойму!"

Система:
1. Определяет эмоциональное состояние как "фрустрированный"
2. Снижает сложность заданий
3. Добавляет эмоциональную поддержку в ответ

### Пример 3: Использование данных из тестов

После теста система:
1. Анализирует ошибки
2. Предлагает рефлексивный вопрос: "Как тебе эта задача?"
3. Адаптирует сложность следующих тестов

## Архитектура

```
AdaptiveEducatorAgent
  ├── Сбор данных из диалогов
  ├── Анализ эмоционального состояния
  ├── Определение стиля обучения
  └── Генерация персонализированных ответов

StudentAnalyticsService
  ├── Интеграция с CognitiveProfile
  ├── Обработка результатов тестов
  └── Управление данными

StudentAnalyticsData (модель)
  ├── AcademicTrait
  ├── BehavioralTrait
  └── ProgressMetrics
```

## Файлы

- `backend/models/student_analytics.py` — модели данных
- `backend/agents/adaptive_educator_agent.py` — основной агент
- `backend/services/student_analytics.py` — сервис управления
- `backend/routes/assistant.py` — API endpoints (обновлён)

## Триггеры для углублённого анализа

1. **Повторяющиеся ошибки** → предложить дополнительные материалы
2. **Долгие паузы** → проверить, нужна ли подсказка
3. **Позитивные реакции на игры** → использовать геймификацию чаще
4. **Низкая мотивация** → добавить поддержку и похвалу
