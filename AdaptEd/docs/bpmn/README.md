# BPMN-схемы дипломного проекта AdaptEd

Диаграммы в формате **BPMN 2.0** (XML), совместимы с [Camunda Modeler](https://camunda.com/download/modeler/), [bpmn.io](https://bpmn.io/) и другими редакторами BPMN.

## Файлы

| Файл | Описание |
|------|----------|
| **AdaptEd_AS_IS.bpmn** | AS-IS: основной процесс обучения (ученик запрашивает адаптивное задание, вводит ответ, получает проверку и объяснение). |
| **AdaptEd_AS_IS_Admin.bpmn** | AS-IS: процесс администрирования (создание админа скриптом, заполнение БД из `seed_credentials.txt`, управление пользователями и контентом). |
| **AdaptEd_TO_BE.bpmn** | TO-BE: целевой процесс с улучшениями (синхронизация правильного ответа из объяснения ИИ, отображение ответа ученика, рекомендации по слабым темам). |

## Как открыть

1. **Camunda Modeler** (рекомендуется): скачайте с [camunda.com/download/modeler](https://camunda.com/download/modeler/), установите, откройте файл `.bpmn`.
2. **Онлайн**: загрузите XML на [demo.bpmn.io](https://demo.bpmn.io/) или [camunda.com/products/camunda-platform/bpmn-engine/](https://camunda.com/products/camunda-platform/bpmn-engine/).
3. **VS Code**: расширение «BPMN Editor» или «Camunda Modeler» (если доступно).

## Краткое содержание AS-IS

- **Обучение**: Вход → выбор раздела → запрос задания (ИИ) → отображение задания → ввод ответа → отправка → проверка → (верно: обновление профиля / неверно: анализ ошибки) → показ результата и объяснения.
- **Админ**: Создание админа скриптом → заполнение БД из файла → вход админа → управление пользователями/контентом → просмотр статистики.

## Краткое содержание TO-BE

- Добавлен шаг **«Синхронизация correctAnswer из объяснения ИИ»** (чтобы правильный ответ совпадал с объяснением, например 1500, а не 1.2).
- В обратной связи явно показываются **«Ваш ответ»** и **«Правильный ответ»**.
- Добавлен шаг **«Рекомендация следующих тем/заданий»** по слабым местам.
- Админ и пользователи создаются один раз (скрипты), без пересоздания админа при каждом старте приложения.
