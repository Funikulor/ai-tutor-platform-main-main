# BPMN-схемы дипломного проекта AdaptEd

Диаграммы в формате **BPMN 2.0** (XML), совместимы с [Camunda Modeler](https://camunda.com/download/modeler/), [bpmn.io](https://bpmn.io/) и другими редакторами BPMN.

## Файлы

| Файл | Описание |
|------|----------|
| **AdaptEd_AS_IS_StudentLearning.bpmn** | AS-IS: основной сквозной процесс персонализированного обучения ученика. Покрывает загрузку профиля, выбор слабой темы, генерацию задания, проверку ответа, классификацию ошибки и обновление аналитики. |
| **AdaptEd_AS_IS_TestHomeworkLifecycle.bpmn** | AS-IS: жизненный цикл теста и домашнего задания. Покрывает ручное и AI-создание теста, назначение ученикам, прохождение, автооценивание, AI-фидбек и просмотр результатов учителем. |
| **AdaptEd_AS_IS_MaterialStudy.bpmn** | AS-IS: процесс изучения материала в библиотеке. Покрывает поиск и выбор материала, фиксацию изучения, обновление `topic_mastery`, баллов, уровня и повторных рекомендаций. |
| **AdaptEd_AS_IS_AdminOperations.bpmn** | AS-IS: административный контур платформы. Покрывает создание администратора, импорт пользователей из `seed_credentials.txt`, управление доступами, контентом и системными настройками. |
| **AdaptEd_TO_BE_ContentRecommendations.bpmn** | TO-BE: целевой единый контур публикации материалов, индексации, grounded-recommendations и замыкания цикла «ошибка/слабая тема → материал → повторная практика». |

## Как открыть

1. **Camunda Modeler** (рекомендуется): скачайте с [camunda.com/download/modeler](https://camunda.com/download/modeler/), установите, откройте файл `.bpmn`.
2. **Онлайн**: загрузите XML на [demo.bpmn.io](https://demo.bpmn.io/) или [camunda.com/products/camunda-platform/bpmn-engine/](https://camunda.com/products/camunda-platform/bpmn-engine/).
3. **VS Code**: расширение «BPMN Editor» или «Camunda Modeler» (если доступно).

## Набор диаграмм

- **Учебный контур ученика**: показывает, как слабые темы и профиль ученика влияют на выбор задания, а результат попытки влияет на следующий шаг обучения.
- **Тесты и домашние задания**: показывает межролевой процесс между учителем, платформой, учеником и AI-сервисом.
- **Библиотека материалов**: показывает, как изучение теории превращается в данные для прогресса и повторных рекомендаций.
- **Администрирование**: показывает эксплуатационный контур платформы, включая seed-наполнение и управление пользователями.
- **TO-BE рекомендации**: показывает целевое улучшение, в котором контент, retrieval и подсказки работают как единый управляемый процесс.

## Что важно для диплома

- Диаграммы отражают **фактическую** логику платформы AdaptEd, а не абстрактный идеальный процесс.
- В `AS-IS` рекомендационный контур описан осторожно: текущая реализация сочетает AI-подсказки, rule-based рекомендации материалов и частичную подготовку к полноценному RAG.
- В `TO-BE` показан целевой переход к единому контуру: **структурированная публикация материалов → индексация → grounded-recommendation → обновление аналитики**.
- BPMN-файлы можно использовать как самостоятельные приложения к ВКР или экспортировать из Camunda Modeler в PNG/SVG для вставки в пояснительную записку.

## Готовые изображения

- Для каждой BPMN-схемы рядом с XML уже подготовлены `SVG`- и `PNG`-версии.
- Их можно вставлять в пояснительную записку как рисунки без дополнительного ручного экспорта.
